# Проект: Система банковского антифрода.

## 1. Бизнес-анализ (Business Understanding)

### Бизнес-цель проекта
Основная цель — минимизация финансовых потерь банка от мошеннических транзакций.  
**Задачи:**
*   Автоматическое выявление фрода в реальном времени.
*   Снижение показателя False Positive (ложных срабатываний), чтобы не блокировать честных клиентов и сохранять их лояльность.
*   Оптимизация работы службы безопасности за счет приоритизации подозрительных операций.
---
## 1.1 Текущая ситуация
*   **Ресурсы:** Разработка на локальном компьютере/Google Colab с использованием GPU для ускорения обучения моделей.
*   **Данные:** Используется датасет  [IEEE-CIS Fraud Detection (Kaggle)](https://www.kaggle.com/competitions/ieee-fraud-detection/overview) в формате csv, содержащий информацию о транзакциях. 
*   **Экспертиза:** Проект опирается на открытые исследования в области финтеха.

### Риски проекта
*   **Дисбаланс классов:** Мошеннических транзакций всего ~3.5%. Это создает риск того, что модель научится распознавать только типичные (честные) операции и будет пропускать фрод.
*   **Объем данных:** 400+ признаков и миллион строк требуют оптимизации памяти и тщательного отбора признаков.
*   **Конфиденциальность:** Большинство данных анонимизированы, что усложняет интерпретацию признаков.
---
## 1.2. Решаемые задачи с точки зрения аналитики (Data Mining goals)

### Постановка задачи
Задача классификации: предсказать вероятность `isFraud` для каждой транзакции.

### Метрики качества
*   **Основная метрика:** **ROC-AUC**. Она позволяет оценить качество ранжирования транзакций по степени риска независимо от выбранного порога вероятности.
*   **Дополнительные метрики:** 
    *   **Precision-Recall Curve:** Важна из-за сильного дисбаланса классов.
    *   **Recall:** Критично "поймать" как можно больше мошенников.

### Критерий успешности
*   **Минимальный порог:** ROC-AUC > 0.85 (базовый уровень для сложных табличных данных).
*   **Оптимальный результат:** ROC-AUC > 0.90 (уровень SOTA решений для данного датасета).
